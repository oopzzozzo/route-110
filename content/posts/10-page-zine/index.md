### 12 頁小書
小學之後這招我只用過一次，用來做我高中的萬年國文暑假作業：「選四大名著的其中十回，簡寫編製成一本小書。」

開學後班上當然就出現各種版本：
- 製作精美，封面紋路剪貼細緻的硬殼書
- A4 紙影印內文，用三國無雙角色充作插圖，再拿釘書機釘一釘
- 乾脆不交，老師也拿我沒輒

我則是拿一張紙，十回加封面封底，共 12 份。中間剪開，折好就算是一本小書了。

```
┌────┬────┬────┬────┬────┬────┐
│    ┊    │    ┊    │    │    │
│ ↓7 ┊ ↓8 │ ↓9 ┊↓10 │↓BC │↓FC │
├────┾━━━━┿━━━━┿━━━━┿━━━━┽────┤
│ ↑6 ┊ ↑5 │ ↑4 ┊ ↑3 │ ↑2 ┊ ↑1 │
│    ┊    │    ┊    │    ┊    │
└────┴────┴────┴────┴────┴────┘
```
*↑ 正著印、↓ 倒著印，BC 是封底、FC 是封面；粗線是中間剪開的那一刀。折出來的書是由右讀到左。*

### 4x 頁小書
至於為什麼 12 頁是折成 2\*6 而不是 3\*4 呢？因為 3\*4 沒辦法折成小書。要 4\*4 才可以。
```
┌────┬────┬────┬────┐
│ ↓7 ┊ ↓8 │ ↓9 ┊↓10 │
├────┾━━━━╈━━━━┽────┤
│ ↑6 ┊ ↑5 ┃↑12 ┊↑11 │
┝━━━━┽────╂────┾━━━━┥
│ ↓3 ┊ ↓4 ┃↓13 ┊↓14 │
├────┾━━━━╇━━━━┽────┤
│ ↑2 ┊ ↑1 │↑FC │↑BC │
└────┴────┴────┴────┘
```

總地來說：
- 偶數乘偶數份就一定可以折成小書。
- 任一邊是奇數份就一定無法折成小書。

原因就留給讀者自己證明！
